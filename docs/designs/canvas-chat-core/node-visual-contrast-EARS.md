# Node Visual Contrast EARS

## Related Documents

- [Canvas Composer and Auto-Reply LLD](./LLD.md)

## Requirements

- **CCHAT-VISUAL-001 (Ubiquitous)**
  The system shall render different visual styles for `human`, `ai`, and `system` nodes.

- **CCHAT-VISUAL-002 (State-driven)**
  While a node is selected, the system shall render a stronger selection outline than unselected nodes.

- **CCHAT-VISUAL-003 (Quality-driven)**
  The system shall use text, border, and background combinations with high contrast suitable for dark canvas usage.

- **CCHAT-VISUAL-004 (Unwanted behavior)**
  If an unrecognized role is encountered, the system shall still render the node with a readable fallback style.
